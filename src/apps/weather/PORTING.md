# Weather port

Adapted from the MIT-licensed [PaperS3Weather](https://github.com/squirmen/PaperS3Weather) project.

Preserved: Open-Meteo current conditions, hourly forecast, weather-code mapping,
timezone-aware hourly indexing, manual refresh, and a ten-minute refresh policy.

Paper OS adaptations: uses fixed Noida coordinates, shared Wi-Fi provisioning,
shared Chrome navigation, and no app-owned deep sleep or display initialization.
